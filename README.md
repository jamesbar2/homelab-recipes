# Homelab Recipes

Open-source Markdown recipes for [The Homelab Cookbook](https://www.james-barnett.com/homelab) on [james-barnett.com](https://www.james-barnett.com).

These are operational playbooks for running real services from a single-node homelab — networking, ingress, secrets, databases, logging, and CI/CD. The site pulls this repository at build time; this repo is content only.
